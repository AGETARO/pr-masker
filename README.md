# PR Masker (PRマスカー) 🧪 β試験運用版

> **「写真アップで、顔ぼかし（モザイク/スタンプ）＆ 広報文（約100字）を一発自動生成」**
> 
> 企業のSNS担当者、学校・自治体の広報、イベント運営者が直面する「参加者の顔出しプライバシーへの配慮」と「SNS向けPR文面（100字程度）の作成負担」をワンクリックで解決するWebサービスです。

---

## 🌟 主な機能・特徴

### 1. 人物の顔を自動検出 ＆ モザイク・スタンプ・ぼかし加工
- **完全ブラウザ完結AI**: Google MediaPipe（BlazeFace WebAssembly）により、画像がお使いの端末（ブラウザ）から外部サーバーへ送信されることなく、完全にローカルで高速検出されます。
- **選べる隠し方**:
  - **モザイク (Pixelate)**: 粗さスライダーで微調整可能（6px〜40px）
  - **スタンプ (Stamp)**: スマイル（😊）、サングラス（😎）、猫（🐱）、犬（🐶）、桜（🌸）、ビジネス匿名（👤）など12種類以上。サイズ倍率も調整可能
  - **すりガラスぼかし (Blur)**: 自然なぼかし加工
- **現場のニーズに応える直感エディタ**:
  - 枠をクリックするだけで「モザイク ⇔ スタンプ ⇔ 解除（この人だけ顔出しOK）」を個別トグル
  - 空白部分をドラッグして「手動マスク枠」を自由に追加（名札や機密書類、検出漏れも一撃でカバー）
  - 「元画像と比較（Before / After）」トグル

### 2. 広報用文面（100文字程度）の自動生成
- **100文字ジャストフィット設計**:
  - X（旧Twitter）やInstagramのキャプションに最適な約100文字（85〜110文字）に厳密調整
  - リアルタイム文字数カウンター ＆ 最適レンジインジケーター（ゲージ表示）
- **選べる4つのトーン＆マナー**:
  - 🌟 **親しみ・SNS向け**（共感、明るさ、絵文字つき）
  - 🏢 **公式・社内報向け**（信頼感、誠実なビジネス文）
  - 🎉 **イベント・大盛況**（熱気、感謝、次回告知）
  - 💼 **採用・日常チーム**（カルチャー、働く仲間募集）
- **キーワード指定**: 「新オフィス」「社内ハッカソン」などを入力すると文面に自然に組み込み
- **ハイブリッド生成エンジン**:
  - **フロントエンド完全セキュア**: ユーザーによるキー入力は一切不要。ブラウザ上にAPIキーは1文字も露出・保存されません。
  - **Gemini Vision APIモード（サーバーサイド）**: ホスティング先の環境変数 `GEMINI_API_KEY` にキーを設定することで、サーバーレス関数（`/api/generate`）を通じて画像の内容（笑顔、議論、雰囲気）を高精度解析して文面を生成します。
  - **スマートAIテンプレート（自動フォールバック）**: サーバーにAPIキーが未設定の場合や通信エラー時でも、内蔵テンプレートエンジンにより即座に何パターンでも自動生成されます。
- **ワンクリック活用**:
  - 「文面をコピー」
  - 「𝕏 で共有」（投稿作成画面が直接開く）
  - 「画像保存 ＆ 文面コピー」（一括完了）

### 3. 試験運用（Beta）を支える安心機能
- **プライバシー安心設計**: 画像データおよび顔検出処理はブラウザ（ローカル）内で完結し、外部サーバーへ保存されません。
- **手元に写真がなくてもすぐ試せる**: オフィス会議・ワークショップのプリセットサンプル写真を搭載。
- **フィードバック機能**: ユーザーの立場（広報、イベント主催など）と満足度星評価・ご要望を受け付け。

## 🚀 起動・利用方法

### ローカルで動かす場合 (Windows)
1. フォルダ内の `start.bat` をダブルクリック（または PowerShellで `powershell -File .\server.ps1` を実行）
2. ブラウザが自動的に開き、`http://localhost:3000/` でサービスが起動します。
   ※ ローカルでもGemini Visionを試したい場合は、PowerShell起動前に `$env:GEMINI_API_KEY="あなたのキー"` を設定するか、未設定のままスマートテンプレートで即座に動作確認できます。

### Web上に公開する場合（推奨ホスティング）

#### 1. Vercel（おすすめ・API環境変数がワンクリックで登録可能）
1. GitHubに本リポジトリをプッシュ
2. [Vercel](https://vercel.com/) にログインし、「Add New Project」からリポジトリをインポート
3. プロジェクト作成時の **「Environment Variables」** に以下を登録：
   - Key: `GEMINI_API_KEY`
   - Value: `（あなたのGemini APIキー）`
4. 「Deploy」をクリックするだけで、1分ほどで独自URL（`https://your-project.vercel.app`）が発行されます。

#### 2. GitHub Pages（テンプレート生成のみで運用する場合）
- GitHubの Settings > Pages で `main` ブランチを指定するだけで公開可能です。
- ※サーバーレス関数は動かないため、内蔵の「スマートAIテンプレート」が自動作動し、完全無料・安全に動作します。

## 💡 試験運用のチェックポイント（検証項目）
1. **顔検出の精度**: 正面顔だけでなく、複数人や少し離れた人物でも検出されるか？
2. **加工の見た目**: モザイクの粗さやスタンプの可愛らしさ・ビジネス利用に耐えうるか？
3. **文面のクオリティ**: 100文字程度で、広報担当者がそのまま使えるレベルになっているか？
4. **使い勝手**: ドラッグ＆ドロップから保存までの手数が最小限でスムーズか？
